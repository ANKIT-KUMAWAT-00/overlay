# HUD Design System & Style Guide

- Background: `rgba(20, 24, 33, 0.88)` with background blur (glassmorphism)
- Border: `1px solid rgba(255, 255, 255, 0.12)`
- Accent Glow: `#3B82F6` (Generating), `#10B981` (Completed), `#EF4444` (Error)
- Corner Radius: `12px`
- Font: SF Pro Display / Inter with JetBrains Mono for code view
