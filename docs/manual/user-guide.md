# OmniAssist User Manual & Guide

## Quick Start
1. Launch OmniAssist: `python main.py`
2. Focus any question or code prompt in your browser or editor.
3. Press `Option+Space` (or `Alt+Space` on Windows) to trigger instant capture.
4. Review verified answer in HUD.
5. Press `Option+Enter` to inject code directly into your active cursor position.
